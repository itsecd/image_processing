## 1. Цель работы

## 2. Теоретический минимум

### 2.1. Задача обнаружения объектов

Задача обнаружения заключается в установлении наличия на изображении объектов с определёнными свойствами и, если объекты обнаружены, в определении их координат.

Основной принцип состоит в сравнении фрагментов исследуемого изображения с некоторым **эталоном** — изображением искомого объекта.

Пусть:

- $t(k,l)$ — функция яркости эталонного объекта;
- $D$ — область определения эталона;
- $x(m,n)$ — исследуемое изображение.

Эталон последовательно перемещается по изображению. В каждом положении определяется степень его сходства с соответствующим фрагментом изображения.

### 2.2. Квадратичная мера различия

Одной из мер различия изображения и эталона является

```math
\varepsilon^2(m,n)
=
\sum_{(k,l)\in D}
\left[
x(m+k,n+l)-t(k,l)
\right]^2.
```

Фрагмент изображения считается похожим на эталон, если

$\varepsilon^2(m,n)<L_\varepsilon,$

где $L_\varepsilon$ — заданный порог.

На практике непосредственно эту величину обычно не вычисляют. Для обнаружения объектов используется взаимная корреляция изображения и эталона.

## 3. Корреляционный метод обнаружения

Взаимная корреляция изображения с эталоном определяется как

```math
B(m,n)
=
\sum_{(k,l)\in D}
x(m+k,n+l)t(k,l).
```

При хорошем совпадении изображения с эталоном значение $B(m,n)$ увеличивается.

Однако величина взаимной корреляции зависит не только от сходства с эталоном, но и от уровня яркости изображения.

Для уменьшения этого влияния может использоваться нормированная взаимная корреляция:

```math
R(m,n)
=
\frac{
\displaystyle
\sum_{(k,l)\in D}
x(m+k,n+l)t(k,l)
}{
\sqrt{
\displaystyle
\sum_{(k,l)\in D}
x^2(m+k,n+l)
}
\sqrt{
\displaystyle
\sum_{(k,l)\in D}
t^2(k,l)
}
}.
```

Если изображение и эталон совпадают с точностью до постоянного неотрицательного множителя, то $R(m,n)=1$.

Объект считается обнаруженным, если $R(m,n)>L_R$, где $L_R$ — порог обнаружения.

### 3.1. Реализация коррелятора

Корреляционная обработка может быть реализована как линейная обработка изображения с маской, соответствующей эталону, повёрнутому на $180^\circ$:

$h(k,l)=t(-k,-l).$

После обработки получается изображение корреляционных пиков.

Высокие значения на таком изображении соответствуют участкам, похожим на искомый объект.

После этого выполняется пороговая обработка:

```math
g(m,n)=
\begin{cases}
0, & B(m,n)\le L_R,\\
1, & B(m,n)>L_R.
\end{cases}
```

## 4. Метод согласованной фильтрации

Корреляционный метод учитывает форму и распределение яркости объекта, но не учитывает свойства фона.

Согласованная фильтрация позволяет учитывать статистические характеристики фона.

Рассматривается модель, в которой наблюдаемое изображение состоит либо только из фона

$x(m,n)=f(m,n),$

либо из объекта и фона

$x(m,n)=t(m,n)+f(m,n),$

где:

- $t(m,n)$ — искомый объект;
- $f(m,n)$ — случайный фон.

Согласованный фильтр выбирается таким образом, чтобы увеличить превышение сигнала объекта над фоном.

Критерий имеет вид

```math
\delta^2
=
\frac{
y_t^2(0,0)
}{
D_{y_f}
}
\rightarrow \max,
```

где:

- $y_t(0,0)$ — отклик фильтра на объект;
- $D_{y_f}$ — дисперсия фона на выходе фильтра.

В частотной области согласованный фильтр определяется выражением

```math
H(e^{i\omega_1},e^{i\omega_2})
=
\frac{
T(e^{-i\omega_1},e^{-i\omega_2})
}{
\Phi_f(e^{i\omega_1},e^{i\omega_2})
},
```

где:

- $T$ — спектр эталона;
- $\Phi_f$ — энергетический спектр фона.

Если фон представляет собой белый шум, согласованный фильтр с точностью до постоянного множителя совпадает с коррелятором.

Если фон коррелирован, перед корреляционной обработкой необходимо выполнить его разбеливание.

## 5. Разбеливание фона

Согласованный фильтр можно условно представить как последовательность двух операций:

1. разбеливание фона;
2. корреляционная обработка разбеленного изображения.

Разбеливающий фильтр преобразует коррелированный фон в фон, близкий по свойствам к белому шуму.

После разбеливания производится корреляция с эталоном.

## 6. Фон с биэкспоненциальной корреляционной функцией

В лабораторной работе фон моделируется случайным полем с биэкспоненциальной корреляционной функцией

```math
B_f(m,n)
=
D_f\rho^{\lvert m\rvert+\lvert n\rvert},
```

где:

- $D_f$ — дисперсия фона;
- $\rho$ — коэффициент корреляции между соседними отсчётами.

Для такого фона разбеливание можно выполнить обработкой изображения окном $3\times3$ с маской

```math
\begin{pmatrix}
a_2 & a_1 & a_2\\
a_1 & 1 & a_1\\
a_2 & a_1 & a_2
\end{pmatrix},
```

где

```math
a_0=
\left(
\frac{1+\rho^2}{1-\rho^2}
\right)^2,
```

```math
a_1=
-\frac{\rho}{1+\rho^2},
```

```math
a_2=
\frac{\rho^2}{(1+\rho^2)^2}.
```

Коэффициент $a_0/D_f$ является масштабным множителем и при обработке может не учитываться, поскольку влияет только на масштаб значений и последующий выбор порога.

Для сценария 2 при $\rho=0.8$

коэффициенты имеют значения

$a_0=20.75,$

$a_1=-0.4878,$

$a_2=0.2380.$

## 7. Эталоны объектов

Тип объекта задаётся преподавателем.

#### Объект `x`


```math
\begin{pmatrix}

\end{pmatrix}
```

```math
\begin{pmatrix}
1 & 1 & 1\\
1 & 0 & 1\\
1 & 1 & 1
\end{pmatrix}
```

#### Объект `⊢`

```math
\begin{pmatrix}
1 & 0 & 0\\
1 & 1 & 1\\
1 & 0 & 0
\end{pmatrix}
```

## 8. Общая схема исследования

1. Сгенерировать изображение фона размером $64\times64$.

2. Фон должен иметь:

   - нулевое среднее;
   - заданную дисперсию $D_f$;
   - заданный коэффициент корреляции $\rho$.

3. Сгенерировать отдельное изображение размером $64\times64$, содержащее набор объектов заданного типа.

4. Размер каждого объекта: $3\times3$.

5. Получить исследуемое изображение суммированием изображения фона и изображения объектов.

6. Объекты не должны пересекаться.

7. Для корреляционного метода выполнить обработку изображения коррелятором.

8. Для согласованной фильтрации:

   - выполнить разбеливание фона;
   - выполнить обработку коррелятором.

9. Для полученного изображения корреляционных пиков:

   - построить гистограмму;
   - визуализировать её;
   - выбрать порог;
   - выполнить пороговую обработку.

10. По итоговому изображению определить:

   - число правильно обнаруженных объектов;
   - число ложных обнаружений;
   - число пропущенных объектов.

Если требуется обнаруживать несколько типов объектов, корреляционная и пороговая обработка выполняются отдельно для каждого типа.

## 10. Правила проведения экспериментов

### 10.1. Синтез данных

- Размер изображения: 64×64 пикселя; размер эталона: 3×3.

- Объекты не должны пересекаться и должны быть достаточно удалены от границ, чтобы окно 3×3 было определено целиком.
- При расчётах использовать вещественные значения яркости: **не обрезать** сумму объекта и фона до диапазона 0–255. Для визуализации допускается настроить масштаб отображения.

### 10.2. Корреляция, порог и координаты

Коррелятор должен вычислять скалярное произведение локального окна изображения и эталона. При реализации именно свёртки маску необходимо предварительно развернуть на 180°. Описать выбранное правило обработки границ (рекомендуется считать отклик только для полностью помещающегося окна).

После пороговой обработки нельзя автоматически считать каждый превышающий порог пиксель отдельным объектом: **выделить локальные максимумы** и исключить повторный подсчёт одного объекта. Указать радиус подавления соседних максимумов (рекомендуется 1–2 пикселя) и правило сопоставления координат с истинными (например, расстояние не более 1 пикселя; один к одному).

**Ложное обнаружение** — выделенная точка, не сопоставленная ни с одним истинным объектом. **Пропуск** — истинный объект, которому не соответствует ни одно обнаружение.

### 15.1. Теория
