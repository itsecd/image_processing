# Модификация лабораторной работы №2. Исследование устойчивости к шуму — три варианта

## 1. Цель исследования

Экспериментально оценить влияние шума на качество выделения контуров и сравнить помехоустойчивость локальных операторов.

Все варианты имеют одинаковую структуру и объём работы, но различаются составом тестового изображения, контрастностью объектов и уровнями шума.

## 2. Общая часть задания

Для своего варианта необходимо:

1. Программно сформировать синтетическое полутоновое изображение размером не менее $256\times256$ пикселей.
2. Одновременно сформировать эталонное бинарное изображение контуров $G$.
3. Добавить к изображению гауссов шум трёх уровней.
4. Добавить импульсный шум «соль и перец» трёх уровней.
5. Применить к исходному и зашумлённым изображениям исследуемые методы выделения контуров.
6. Выполнить пороговую обработку с заранее зафиксированным порогом.
7. Вычислить `Precision`, `Recall` и $F_1$.
8. Построить графики зависимости $F_1$ от уровня шума.
9. Сравнить экспериментальные результаты с теоретической оценкой помехоустойчивости операторов.

Для воспроизводимости эксперимента необходимо использовать фиксированное начальное состояние генератора случайных чисел, например `seed = 42`.

## 3. Варианты тестового изображения

### Вариант 1. Геометрические объекты с высоким контрастом

Создать изображение со следующими объектами:

- белый прямоугольник яркости $255$;
- серый круг яркости $180$;
- диагональная линия яркости $120$;
- однородный фон яркости $0$.

Объекты не должны пересекаться. Эталонное изображение должно содержать их внешние границы толщиной в один элемент.

### Вариант 2. Объекты с различной контрастностью

Создать изображение со следующими объектами:

- светлый треугольник яркости $220$;
- кольцо яркости $150$;
- прямоугольник яркости $90$;
- однородный фон яркости $40$.

Хотя бы один объект должен иметь относительно небольшой перепад яркости относительно фона. Это позволит проверить, какие методы раньше начинают терять слабые контуры.

### Вариант 3. Тонкие и близко расположенные объекты

Создать изображение со следующими объектами:

- две параллельные линии толщиной $1$–$2$ элемента;
- две близко расположенные прямоугольные области;
- окружность толщиной $1$–$2$ элемента;
- однородный фон яркости $20$.

Яркости объектов выбрать из диапазона $120$–$255$. Расстояние между близко расположенными объектами должно составлять $3$–$5$ элементов. Этот вариант позволяет исследовать сохранение тонких границ и слияние соседних контуров.

## 4. Уровни шума по вариантам

Для гауссова шума используется модель

```math
\widetilde f(m,n)=\operatorname{clip}\bigl(f(m,n)+\varepsilon(m,n),0,255\bigr),
\qquad
\varepsilon(m,n)\sim\mathcal N(0,\sigma^2).
```

При добавлении импульсного шума каждый элемент заменяется на $0$ с вероятностью $p/2$, на $255$ с вероятностью $p/2$ и сохраняет исходное значение с вероятностью $1-p$.

| Вариант | Уровни гауссова шума $\sigma$ | Уровни импульсного шума $p$ |
|---:|---|---|
| 1 | $5$, $15$, $30$ | $0{,}01$, $0{,}03$, $0{,}05$ |
| 2 | $10$, $25$, $40$ | $0{,}02$, $0{,}04$, $0{,}06$ |
| 3 | $8$, $20$, $35$ | $0{,}01$, $0{,}025$, $0{,}05$ |

Готовые функции добавления шума использовать нельзя.

## 5. Исследуемые методы

В каждом варианте необходимо сравнить:

1. простой градиентный метод с точным вычислением модуля градиента;
2. комбинированный оператор Лапласа;
3. оператор Прюитт;
4. согласованный оператор Лапласа.

Дополнительно можно исследовать традиционный и диагональный лапласианы.

Все операторы должны использовать собственную реализацию локальной обработки из основной части лабораторной работы.

## 6. Выбор порога

Для каждого метода порог выбирается по результату обработки синтетического изображения без шума. Можно использовать гистограмму отклика либо перебрать возможные значения и выбрать порог с максимальным $F_1$.

После выбора порог фиксируется и используется без изменения для всех уровней обоих видов шума. Для каждого метода допускается свой порог.

## 7. Метрики качества

Пусть $P$ — найденные бинарные контуры, а $G$ — эталонные контуры.

Для учёта возможного смещения границы на один элемент необходимо самостоятельно выполнить расширение контуров окном $3\times3$. Обозначим результат расширения через $D(\cdot)$.

```math
\operatorname{Precision}
=
\frac{|P\cap D(G)|}{|P|}.
```

```math
\operatorname{Recall}
=
\frac{|G\cap D(P)|}{|G|}.
```

```math
F_1
=
2\cdot
\frac{\operatorname{Precision}\cdot\operatorname{Recall}}
{\operatorname{Precision}+\operatorname{Recall}}.
```

Если знаменатель равен нулю, значение соответствующей метрики принимается равным нулю.

В отчёте необходимо представить:

- номер выполненного варианта;
- исходное синтетическое изображение;
- эталонное изображение контуров;
- изображения со всеми уровнями гауссова и импульсного шума;
- бинарные контуры для изображения без шума;
- бинарные контуры при максимальном уровне каждого вида шума;
- таблицу метрик для всех методов и уровней шума;
- график зависимости $F_1$ от $\sigma$;

## 9. Особенности выводов по вариантам

### Для варианта 1

Объяснить, насколько быстро методы теряют качество при увеличении шума на изображении с чёткими высококонтрастными границами.

### Для варианта 2

Определить, какие методы лучше сохраняют слабоконтрастные границы и при каких уровнях шума эти границы перестают обнаруживаться.

### Для варианта 3

Проанализировать сохранение тонких линий, появление разрывов и возможное слияние близко расположенных контуров.

## 10. Общие выводы

Независимо от варианта необходимо указать:

- наиболее устойчивый метод для гауссова шума;
- наиболее устойчивый метод для импульсного шума;
- характер изменения `Precision`, `Recall` и $F_1$;
- методы, создающие наибольшее число ложных контуров;
- методы, чаще теряющие истинные границы;
- соответствие результатов коэффициентам усиления шума $Q$;
- причины различной реакции операторов на два вида шума.

## 11. Требования к реализации

Необходимо самостоятельно реализовать:

- формирование синтетического изображения и эталонных контуров;
- добавление гауссова и импульсного шума;
- применение исследуемых операторов;
- пороговую обработку;
- расширение бинарных контуров;
- вычисление метрик.

Допускается использовать библиотеки для работы с массивами, генерации случайных чисел, визуализации и построения графиков.

Готовые детекторы границ, функции добавления шума и готовые функции вычисления метрик использовать нельзя.
